# Pokédex

A simple Pokédex with basic functions.

## Description

This Pokédex has 8 different main functions.

Option 1 will show all available Pokémon with their corresponding 
attributes and attacks.

Option 2 will give you the option to register a new Pokémon to the
Pokédex.

Option 3 will give you the option to edit an existing Pokémon.

Option 4 will give you the option to
remove a registered Pokémon from the Pokédex.

Option 5 will save changes to a file/files.

Option 6 will upload from a file/files.

Option 7 will factory reset the Pokédex.

Option 8 will save changes and close Pokédex.




### Executing program

How to run the program:

The Pokédex is pretty simple to run and navigate in.

All options except for option 3 are straighforward to use.
Choosing option 3 (editing an existing Pokémon) will open a submenu
where the user can choose which aspects of the chosen Pokémon they
wish to edit. The user has in this case the freedom to change
the Pokémon's name, HP and type/types. The user can even teach 
a new attack move to the Pokémon or remove an attack move from the chosen
Pokémon if they wish so. 

At last, the user can return to the main menu by opting for option 6 in
the submenu.
